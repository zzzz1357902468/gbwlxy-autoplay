# gbwlxy-autoplay

灯塔·山东干部网络学院 的连续播放用户脚本（Tampermonkey）。

进入某个**专栏**（如「深入学习贯彻习近平党建思想」）→ 点「收集本专栏」→ 生成可视化播放列表 → 点「开始」→ 按列表顺序逐门播放，播完自动下一门。

> 仅用于个人学习场景下的播放自动化演示。请遵守所在平台的使用规则。

---

## 功能

| 功能 | 说明 |
|---|---|
| 收集专栏课程 | **拦截页面自身的 XHR / fetch 响应**，从 JSON 里按结构识别课程（id + name + creditHour 等），不依赖 CSS 类名 |
| 可视化列表 | 面板内列出全部课程，含学时数；当前播放高亮，点击任意一条跳播 |
| 测试标记 | 带随堂测试的课程显示 `⚠含测试` 并置灰（这类课播完也不计学时） |
| 顺序播放 | 播完自动打开下一门，直到列表结束 |
| 1.5 倍速 | 优先点击平台自带倍速控件，避免被判"倍速过快"；无控件时回退 `playbackRate`；上限锁死 1.5 |
| 跳过随堂测试 | 检测 `#/examManage/startExam` 路由自动点「退出」，继续下一门 |
| 诊断 | 输出捕获到的接口 URL、解析出的课程、DOM 兜底信息，一键复制 |

## 不做什么

- 不拖进度条、不跳片段
- 不调用学习/上报接口，不伪造学时
- 不替用户答题（随堂测试一律退出跳过，该门不计学时）

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 把 `gbwlxy-autoplay.user.js` 拖进浏览器窗口，或新建脚本粘贴后保存。
3. Chrome 138+ / Edge 需在扩展详情里打开「允许用户脚本」（Allow User Scripts）。

## 使用

1. 登录后进入一个**专栏**详情页（课程列表那页），等列表加载出来。
2. 面板点 **「收集本专栏」**。
   - 显示 `采集中… 第 N 轮，累计 M 门`，最多 15 轮
   - 成功：`✅ 采集完成 49 门`，列表里带学时与测试标记
3. 点 **「开始」**，面板显示 `49 门 ｜播放中 ｜3. 课程名 ｜1.5x`。

### 抓不到课程怎么办

面板会显示红色 `未从接口里解析到课程`。点 **「诊断」**（结果自动复制到剪贴板），重点看三项：

- `capturedResponses` / `capturedUrls`：有没有捕获到接口；为 0 说明列表走的是 iframe、WebSocket 或服务端渲染
- `responsesWithCourses`：哪些响应里被识别出了课程
- `listContainers`：页面里像列表的容器，用于改选择器

## 工作原理

纯前端自动化，不碰学习接口：

- **采集**：脚本在 `document-start` 挂钩 `XMLHttpRequest` 与 `fetch`，把页面自己拿到的 JSON 缓存下来；再递归遍历，按"课程对象"特征（含 `id`/`courseId` + `name`，且带 `creditHour`/`showCourseDuration`/`assessementType` 等字段）识别课程。
- **播放**：标准 video.js `<video class="vjs-tech">`，无 iframe，直接控制。
- **倍速**：优先点 `.vjs-playback-rate` 菜单，使播放器内部状态与实际速率一致。
- **考试页**：带随堂测试的课程播完会整页跳到 `#/examManage/startExam?examId=...`，脚本点 `button.exitBtn` 退出。
- **状态存储**：站点路由跳转会清空 `localStorage` 但保留 `sessionStorage`，故列表与运行状态存 sessionStorage。

## 已知限制

- 若专栏课程列表由**服务端渲染或 iframe** 提供，接口嗅探会失效，需要改为 DOM 方案（届时用「诊断」的 `listContainers` 定位）。
- 带随堂测试的课程拿不到学时（平台通常要求答题合格）。
- 1.5 倍速是否影响学时入账取决于平台计时方式，建议先完成一门并核对「已完成学时」。
- 依赖平台接口字段名，改版后可能需要更新。
