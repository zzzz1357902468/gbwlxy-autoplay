# gbwlxy-autoplay

灯塔·山东干部网络学院 的连续播放用户脚本（Tampermonkey）。

进入某个**专栏**（如「深入学习贯彻习近平党建思想」）→ 点「收集本专栏」→ 生成可视化播放列表 → 点「开始」→ 按列表顺序逐门播放，播完自动下一门。

> 仅用于个人学习场景下的播放自动化演示。请遵守所在平台的使用规则。

---

## 功能

| 功能 | 说明 |
|---|---|
| 收集专栏课程 | 扫描专栏页的课程卡片，自动翻页收集，生成播放列表 |
| 可视化列表 | 面板内列出全部课程，当前播放高亮，可点击任意一门跳转播放 |
| 顺序播放 | 播完自动打开下一门，直到列表结束 |
| 1.5 倍速 | **优先点击平台自带的倍速控件**（避免被判"倍速过快"），无该控件时回退为直接设置 `playbackRate`；上限锁死 1.5 |
| 跳过随堂测试 | 检测到 `#/examManage/startExam` 路由自动点「退出」，继续下一门 |
| 诊断 | 「诊断」按钮把页面结构、课程卡片数、倍速控件等打印到控制台，便于反馈问题 |

## 不做什么

- 不拖进度条、不跳片段
- 不调用任何学习/上报接口，不伪造学时
- 不替用户答题（随堂测试一律退出跳过，该门不计学时）
- 不绕平台的反挂机检测

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 把 `gbwlxy-autoplay.user.js` 拖进浏览器窗口，或新建脚本粘贴内容后保存。
3. Chrome 138+ / Edge 需要在扩展详情里打开「允许用户脚本」（Allow User Scripts），否则脚本不会执行。

## 使用

1. 登录后进入「专栏推荐」，点开一个专栏（能看到整页课程列表的那一页）。
2. 右下角面板点 **「收集本专栏」**，控制台会打印每页收集到多少门。
3. 收集完成后列表出现在面板里，点 **「开始」**。
4. 面板显示 `49 门 ｜播放中 ｜3. xxx ｜1.5x`，之后自动跑完整个专栏。

停止：再点一次「开始/停止」。

### 抓不到课程怎么办

点面板上的 **「诊断」**，控制台会输出一段 JSON（课程卡片数、带 ID 的数量、是否有分页、倍速控件是否存在、页面上的告警文字）。把这段发出来即可定位。

## 工作原理

纯前端自动化，不碰学习接口：

- 课程卡片选择器：`.course-list-item` / `.video-warp-start` / `[class*="course-item"]`，优先从卡片内 `<a href*="courseId=">` 解析课程 ID；解析不到时退化为"回专栏页按序号点击第 N 张卡片"。
- 播放器是标准 video.js `<video class="vjs-tech">`，无 iframe。
- 带随堂测试的课程播放结束后会整页跳 `#/examManage/startExam?examId=...`，脚本检测该路由并点 `button.exitBtn`。
- 站点路由跳转会清空 `localStorage`，但保留 `sessionStorage`，所以列表与运行状态存在 sessionStorage。
- 倍速优先通过 `.vjs-playback-rate` 菜单项设置，使播放器内部状态与元素一致，避免平台判定异常。

## 已知限制

- **专栏页的 DOM 结构未在真实站点上验证过**（开发环境登录受阻）。若「收集本专栏」抓到 0 门，请反馈「诊断」输出。
- 带随堂测试的课程拿不到学时（平台通常要求答题合格）。
- 1.5 倍速是否影响学时入账取决于平台计时方式，建议先完成一门课并核对「已完成学时」。
- 依赖页面 DOM，平台改版后可能需要更新选择器。
