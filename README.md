# gbwlxy-autoplay

灯塔·山东干部网络学院 的连续播放用户脚本（Tampermonkey）。

进入某个**专栏**（如「深入学习贯彻习近平党建思想」）→ 点「收集本专栏」→ 生成可视化播放列表 → 点「开始」→ 按列表顺序逐门播放，播完自动下一门。

> 仅用于个人学习场景下的播放自动化演示。请遵守所在平台的使用规则。

---

## 功能

| 功能 | 说明 |
|---|---|
| 收集专栏课程 | 优先扫描页面里所有 `a[href*="courseId="]` 链接（不依赖卡片类名），其次扫描课程卡片；支持自动翻页 |
| 可视化列表 | 面板内列出全部课程，当前播放高亮，点击任意一条可跳播 |
| 顺序播放 | 播完自动打开下一门，直到列表结束 |
| 1.5 倍速 | 优先点击平台自带的倍速控件，避免被判"倍速过快"；无该控件时回退设置 `playbackRate`；上限锁死 1.5 |
| 跳过随堂测试 | 检测 `#/examManage/startExam` 路由自动点「退出」，继续下一门 |
| 诊断 | 一键采集页面结构，**复制到剪贴板**并显示在面板文本框里，便于反馈 |

## 不做什么

- 不拖进度条、不跳片段
- 不调用任何学习/上报接口，不伪造学时
- 不替用户答题（随堂测试一律退出跳过，该门不计学时）

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 把 `gbwlxy-autoplay.user.js` 拖进浏览器窗口，或新建脚本粘贴后保存。
3. Chrome 138+ / Edge 需在扩展详情里打开「允许用户脚本」（Allow User Scripts）。

## 使用

1. 登录后进入一个**专栏**详情页（能看到整页课程列表的那一页）。
2. 面板点 **「收集本专栏」**。
   - 状态行上方会实时显示 `采集中… 第 1 页，本页 20 门，累计 20 门`
   - 成功后显示 `✅ 采集完成 49 门（49 门带ID）`
3. 点 **「开始」**，面板显示 `49 门 ｜播放中 ｜3. 课程名 ｜1.5x`。

### 抓不到课程怎么办

面板会显示红色提示 `未找到课程（页面共 N 个链接）`。此时点 **「诊断」**：

- 诊断结果会自动复制到剪贴板（同时显示在面板下方文本框）
- 直接粘贴发出来，即可定位是选择器问题还是页面结构差异

## 工作原理

纯前端自动化，不碰学习接口：

- 采集优先用页面内 `<a href*="courseId=">` 链接，天然带 ID，跳转最稳；没有链接时退回卡片 + Vue 实例取 ID；再不行则"回专栏页按序号点击第 N 张卡片"。
- 播放器是标准 video.js `<video class="vjs-tech">`，无 iframe。
- 带随堂测试的课程播放结束后整页跳 `#/examManage/startExam?examId=...`，脚本检测并点 `button.exitBtn` 退出。
- 站点路由跳转会清空 `localStorage` 但保留 `sessionStorage`，因此列表与运行状态存 sessionStorage。
- 倍速优先通过 `.vjs-playback-rate` 菜单设置，使播放器内部状态与实际速率一致。

## 已知限制

- **专栏页真实 DOM 未在真实站点验证过**（开发环境登录受阻）。抓不到时请反馈「诊断」输出。
- 带随堂测试的课程拿不到学时（平台通常要求答题合格）。
- 1.5 倍速是否影响学时入账取决于平台计时方式，建议先完成一门课并核对「已完成学时」。
- 依赖页面 DOM，平台改版后可能需要更新选择器。
