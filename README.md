# gbwlxy-autoplay

灯塔·山东干部网络学院 的连续播放用户脚本（Tampermonkey）。

点进任意一门课 → 点「开始」→ 以 1.5 倍速播放 → 播完自动顺着页面底部的「课程推荐」继续下一门 → 循环。
遇到随堂测试自动退出跳过（不答题）。

> 仅用于个人学习场景下的播放自动化演示。请遵守所在平台的使用规则。

---

## 功能

| 功能 | 说明 |
|---|---|
| 自动播放 | 接管页面 `<video>`，被暂停自动续播 |
| 1.5 倍速 | 平台把倍速重置回 1x 时会自动改回；面板可切 1 / 1.25 / 1.5 / 2 |
| 自动下一门 | 播完自动点页面底部「课程推荐」里第一门没看过的课 |
| 跳过随堂测试 | 带测试的课播完会整页跳到考试页，脚本自动点「退出」继续 |
| 防重复 | 看过的课记在 sessionStorage，不会在两门课之间来回跳 |

## 不做什么

- 不拖进度条、不跳片段、不倍速以外的加速
- 不调用任何学习/上报接口，不伪造学时
- 不替用户答题（随堂测试一律退出跳过，该门不计学时）
- 不绕过平台的反挂机检测

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 把 `gbwlxy-autoplay.user.js` 拖进浏览器窗口，或新建脚本粘贴内容后保存。
3. Chrome 138+ / Edge 需要在扩展详情里打开「允许用户脚本」（Allow User Scripts），否则脚本不会执行。

## 使用

1. 登录后从课程列表点进任意一门课（进入课程详情页）。
2. 右下角面板点「开始」。
3. 面板显示 `运行中 ｜123/1413s ｜1.5x` 即正常工作。

面板上还有「重置记录」（清空已看课程）和倍速下拉框。

## 工作原理

纯前端自动化，不碰网络接口：

- 播放器是标准 video.js `<video class="vjs-tech">`，无 iframe，`playbackRate` 可直接设置。
- 页面底部的推荐课程是 `.course-list-item`，点击即路由到下一门课。
- 带随堂测试的课程，播放结束后平台会整页跳到 `#/examManage/startExam?examId=...`；脚本检测该路由并点击 `button.exitBtn` 退出。
- 站点在路由跳转时会清空 `localStorage`，但保留 `sessionStorage`，因此运行状态存在 sessionStorage。
- 跳下一门是整页刷新，脚本通过 `@run-at document-start` 重新注入后自动续播。

## 已知限制

- **带随堂测试的课程拿不到学时**（平台规则通常要求答对一定题数），脚本只跳过。
- 1.5 倍速是否影响学时入账取决于平台计时方式，建议先完成一门课并核对「已完成学时」。
- 依赖页面 DOM 结构，平台改版后可能需要更新选择器。
